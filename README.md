# 코드루트 · CodeRoute

**개념을 배우고, 직접 코드를 작성하고, 채점 결과로 확인하는 알고리즘 학습 도구입니다.**

Python·Java·C++·C로 기초부터 심화까지 학습할 수 있습니다. 단계별 설명과 실행 예제를 읽고, 연결된 문제를 풀며, 막히는 부분은 3단계 힌트와 풀이 해설로 확인합니다. 프로그램과 채점기는 내 PC에서 실행되고 학습 기록도 내 PC에 저장됩니다.

[공식 안내](https://coderoute-info.pages.dev) · [시작하기](#시작하기) · [학습 방법](#학습-방법) · [기록과 업데이트](#기록과-업데이트) · [최신 배포](https://github.com/dang0321/coderoute-launcher/releases/latest) · [문제 제보](https://github.com/dang0321/coderoute-launcher/issues)

## 코드루트 소개

| 항목 | 내용 |
|---|---|
| 현재 배포 | v0.1.2 · Windows 로컬 베타 |
| 지원 언어 | Python · Java · C++ · C |
| 학습 콘텐츠 | 265문제 · 53개 학습 과정 · 모든 문제의 3단계 힌트와 풀이 해설 |
| 이용 방식 | 실행기로 준비한 뒤 내 PC의 웹 브라우저에서 이용 |
| 채점 방식 | 이용자 PC의 Docker 컨테이너에서 코드 실행 |
| 학습 기록 | 로컬 계정별 저장, 개인 기록 파일 교환, 선택한 Google Drive로 동기화 |
| 화면 모드 | 라이트 모드 · 다크 모드 |

이 저장소는 코드루트를 내려받고 실행하는 **공개 실행기 저장소**입니다. 개발 원본 저장소는 비공개로 유지하며, 원본 저장소 접근 권한이나 개발자의 GitHub 토큰 없이 이용할 수 있습니다. 운영자의 PC가 켜져 있을 필요는 없습니다.

### 주요 기능

- **문제 풀기**: 난이도와 유형으로 문제를 찾고, 선택한 언어로 코드를 작성해 제출합니다.
- **단계별 학습**: 개념 → 실행 예제 → 연결 문제 순서로 학습합니다.
- **힌트와 해설**: 힌트를 차례로 확인하고 풀이 근거, 예제 추적, 시간·공간 복잡도와 언어별 코드를 살펴봅니다.
- **코드 입력기**: 문법 색상, 자동완성, 들여쓰기, 괄호·따옴표 자동 닫기를 지원합니다.
- **자동 채점**: 정답·오답·시간 초과·실행 오류·컴파일 오류 등의 결과를 확인합니다.
- **학습 기록**: 풀이 초안, 북마크, 읽은 단원, 언어별 해결 기록, 과정 진행률과 제출 이력을 관리합니다.

입출력·조건문·반복문부터 정렬·이분 탐색·자료구조·DFS/BFS·그리디·DP·최단 경로를 다룹니다. 이후 트리·문자열 알고리즘·구간 자료구조·네트워크 유량·이분 매칭까지 이어집니다. 같은 문제를 여러 언어로 풀 수 있으며, 265문제는 언어별 중복을 합친 수가 아닙니다.

## 시작하기

### 1. 실행 환경 준비

| 준비할 것 | 조건과 공식 안내 |
|---|---|
| Windows PC | 현재 실행 패키지는 Windows x64용입니다. Docker Desktop의 Windows 요구 사항도 충족해야 합니다. |
| Python | **CPython 3.11·3.12·3.13 중 하나의 64비트 버전**이 필요합니다. [Windows용 Python 다운로드](https://www.python.org/downloads/windows/)에서 준비할 수 있습니다. 기존에 지원 버전이 있으면 3.13을 추가로 설치할 필요가 없습니다. |
| Docker Desktop | **Linux 컨테이너 엔진**을 실행해 주세요. [Windows 설치 안내](https://docs.docker.com/desktop/setup/install/windows-install/)를 참고하세요. |
| 인터넷 | 최초 설치와 실행 패키지·의존성·채점 이미지 다운로드, 업데이트 확인에 필요합니다. |
| 브라우저 | 로컬 웹 화면에 접속할 브라우저가 필요합니다. |

PowerShell 또는 명령 프롬프트에서 아래 명령으로 Python 준비 상태를 확인할 수 있습니다.

```powershell
python --version
```

#### Python 호환성과 PyPy

코드루트를 실행하는 데 필요한 Python과, 평소 IDE에서 실습할 때 선택하는 Python은 구분됩니다. 현재 Windows 배포본의 지원 범위는 다음과 같습니다.

| PC에 준비된 환경 | 코드루트 실행 | 설명 |
|---|---|---|
| CPython 3.11 64비트 | 가능 | 3.11용 실행 패키지를 자동 선택합니다. |
| CPython 3.12 64비트 | 가능 | 3.12용 실행 패키지를 자동 선택합니다. |
| CPython 3.13 64비트 | 가능 | 3.13용 실행 패키지를 자동 선택합니다. |
| PyPy만 설치됨 | 불가 | 현재 배포본은 CPython용 바이트코드이므로 PyPy로 실행할 수 없습니다. |
| PyPy와 위 지원 CPython이 함께 설치됨 | 가능 | 실행기가 지원 CPython을 찾을 수 있어야 합니다. PyPy로 실습하는 환경은 유지해도 됩니다. |
| 그 밖의 Python 버전 또는 32비트 Python만 설치됨 | 지원하지 않음 | 지원되는 CPython 3.11·3.12·3.13 64비트가 필요합니다. |

**Python 3.11이나 3.12가 이미 있다면 3.13을 추가로 설치할 필요가 없습니다.** 예를 들어 VS Code나 PyCharm에서 PyPy로 알고리즘을 실습하더라도, 같은 PC의 지원 CPython을 실행기가 찾을 수 있으면 코드루트를 이용할 수 있습니다. **PyPy를 삭제하거나 IDE의 실습 인터프리터 설정을 바꿀 필요는 없습니다.**

Windows Python Launcher(`py`)가 있으면 3.13 → 3.12 → 3.11 순서로 찾고, 없으면 PATH의 `python`을 검사합니다. 기존 설치는 코드루트 전용 가상환경의 Python을 우선 사용합니다. 단순히 CPython이 설치되어 있어도 `py`나 PATH에서 찾을 수 없는 상태라면 실행 환경을 먼저 확인해야 합니다.

PATH의 `python`이 어떤 구현체·버전·비트인지 확인하려면 다음 명령을 사용합니다.

```powershell
python -c "import sys, struct; print(sys.implementation.name, sys.version.split()[0], str(struct.calcsize('P') * 8) + '-bit')"
```

예를 들어 `cpython 3.11.9 64-bit`라면 지원 범위입니다. `pypy`가 나오면 그 명령이 가리키는 Python은 PyPy입니다. `py`가 설치된 PC에서는 `py -0p`로 다른 등록된 Python도 확인할 수 있습니다.

이 조건은 **코드루트 프로그램을 실행하는 환경**에 대한 안내입니다. 이용자 PC의 Python 버전과 제출 코드를 실행하는 Docker 채점 환경은 별개이며, 현재 Python 제출은 Docker의 CPython 3.13에서 채점합니다. Java·C++·C 실행 도구도 채점 이미지에서 준비하므로 PC에 각각 설치할 필요가 없습니다.

Python·Docker 설치와 PC에 필요한 WSL·가상화 설정, 관리자 확인, 재부팅은 직접 진행해야 합니다. 실행기는 그 이후 코드루트의 가상환경·Python 패키지·학습 DB·채점 이미지를 준비합니다. 외부 프로그램의 이용 조건은 각 공식 안내를 확인해 주세요.

### 2. 코드루트 내려받기

**Git 없이 시작하려면** 저장소 상단의 **Code → Download ZIP**을 누른 뒤, 쓰기 가능한 폴더에 압축을 모두 풀어 주세요. ZIP 안에서 `start.cmd`만 따로 실행하지 마세요.

Git을 사용한다면 다음 명령으로 내려받습니다.

```powershell
git clone https://github.com/dang0321/coderoute-launcher.git
cd coderoute-launcher
```

[Release에 첨부된 실행 패키지](https://github.com/dang0321/coderoute-launcher/releases/latest)는 실행기가 자동으로 받습니다. 처음 시작할 때 직접 압축을 풀거나 개발 원본을 내려받을 필요는 없습니다.

### 3. 시작과 종료

1. **Docker Desktop을 실행**하고 Linux 엔진이 준비될 때까지 기다립니다.
2. 내려받은 폴더에서 **`start.cmd`를 더블클릭**합니다. PowerShell에서는 `.\start.cmd`를 실행합니다.
3. 최초 실행 시 패키지 다운로드, 가상환경·의존성 설치, 학습 데이터와 채점 이미지 준비를 기다립니다. PC와 네트워크 상태에 따라 시간이 걸릴 수 있습니다.
4. 준비가 완료되면 브라우저가 열립니다. 자동으로 열리지 않으면 [http://127.0.0.1:8000/](http://127.0.0.1:8000/)에 접속합니다.
5. 이용을 마칠 때는 **`stop.cmd`를 실행**합니다. 채점 중인 작업이 있다면 끝난 뒤 종료해 주세요.

시작 창을 닫는 것만으로 백그라운드 작업자가 모두 종료되는 것은 아닙니다. 종료에는 `stop.cmd`를 사용해 주세요.

## 학습 방법

1. **로컬 계정 만들기**: 코드루트 화면의 회원가입으로 계정을 만들고 로그인합니다. 계정은 해당 설치 폴더의 기록을 구분하는 용도이며, 중앙 서버의 공통 계정이 아닙니다.
2. **과정 또는 문제 선택하기**: 처음 학습한다면 **단계별 학습**에서 언어와 과정을 고릅니다. 바로 연습하려면 **문제 풀기**에서 문제를 찾습니다.
3. **코드 작성과 제출**: 개념과 예제를 확인한 뒤 코드를 작성하고 제출해 판정을 확인합니다. 막히면 힌트와 해설을 활용합니다.
4. **다음에 이어서 풀기**: 떠나기 전에 **초안 저장**을 누릅니다. **학습 기록**에서 초안·북마크·진행률·내 제출 이력을 확인하고 이어서 학습합니다.

Java는 Java 21 기준으로 `package` 선언 없이 `public class Main`을 작성합니다. C++는 C++17, C는 C17 기준으로 채점합니다.

기본 배포물에는 이메일 발송용 SMTP 설정이 포함되지 않습니다. 실제 이메일 인증·비밀번호 복구 메일 발송에는 별도 설정이 필요합니다. 이메일을 입력했다고 바로 복구 메일을 받을 수 있는 상태로 가정하지 말고, 로컬 계정의 비밀번호와 중요한 기록을 보관해 주세요.

## 기록과 업데이트

### 기록 저장과 다른 PC로 옮기기

계정·풀이·진행도는 실행기 폴더 안의 **`.coderoute/home/`**에 저장됩니다. **업데이트 때문에 `.coderoute` 폴더를 삭제하지 마세요.** 새 폴더에 다시 내려받으면 이전 설치의 기록이 자동으로 따라오지 않습니다.

다른 PC로 옮길 때는 다음 순서를 사용합니다.

1. 기존 PC의 **학습 기록 → 개인 기록 내보내기**에서 파일을 저장합니다.
2. 다른 PC에 코드루트를 준비하고 로컬 계정으로 로그인합니다.
3. **학습 기록 → 개인 기록 가져오기**에서 내용을 미리 확인한 뒤 합칩니다.

다른 PC에서 같은 계정명을 만드는 것만으로 기록이 연결되지는 않습니다. 내보낸 파일에는 개인 풀이 코드가 들어 있으므로 공개 저장소나 Issues에 첨부하지 마세요.

### Google Drive로 여러 PC에서 이어서 학습하기

**v0.1.1부터 운영용 Google 연결 설정을 포함합니다.** 이용자가 Google Cloud 프로젝트나 인증 JSON을 직접 만들 필요는 없습니다. Drive 연결은 선택 사항이며, 연결하지 않아도 로컬 학습과 개인 기록 파일 교환을 이용할 수 있습니다.

1. **학습 기록 → Google Drive 연결·동기화 설정**에서 Google 계정을 연결합니다.
2. Google 화면에서 계정과 요청 권한을 확인하고 동의합니다. 권한은 계정 식별·이메일·코드루트 전용 Drive 영역이며, 전체 Drive 파일 접근을 요청하지 않습니다.
3. **Drive 기록 검사·변경 미리보기**로 내용을 확인한 뒤 전송 동의와 **확인한 기록 동기화**를 진행합니다. 연결 버튼만으로 풀이 기록을 올리지는 않습니다.
4. 다른 PC에서도 로컬 계정으로 로그인하고 **같은 Google 계정**을 연결합니다. 검사 결과와 본인 기록 연결을 확인해 기록을 합칩니다. Google 연결이 로컬 로그인 자체를 대체하지는 않습니다.
5. 첫 수동 동기화를 완료한 뒤 원하는 PC에서 **자동 동기화**를 켭니다. 로그인한 코드루트 화면이 열려 있고 보이는 동안 약 2분 간격으로 저장된 기록을 반영합니다. 창을 닫거나 PC가 꺼져 있으면 전송하지 않습니다.

풀이 코드·초안의 이전 이력·완료된 제출·북마크·읽은 단원이 본인 Drive의 앱 전용 영역에 저장됩니다. 저장 버튼을 누르지 않은 편집 내용은 전송하지 않습니다. 서로 충돌한 초안은 보존하며 개인 기록 파일 화면에서 확인할 수 있습니다. 전송 내용은 별도로 암호화되지 않으며, Google 접근 정보는 각 Windows PC에서 보호합니다.

기존에 개발용 Google 설정을 직접 사용한 경우에는 설정을 자동 교체하지 않습니다. 서로 다른 Google 앱의 Drive 저장 영역도 자동 이전되지 않으므로 먼저 기록 파일을 내보내 보관하고 새 운영용 연결로 옮길 때 복원 내용을 확인해 주세요.

### 자동 업데이트

- 실행기는 처음 설치한 뒤 **시작할 때 최대 24시간에 한 번** 이 저장소의 정식 Release를 확인합니다. 계속 켜 둔 동안 주기적으로 새 프로그램을 적용하는 방식은 아닙니다.
- 새 버전이 있으면 다운로드 파일을 검증하고, DB 백업과 개인 기록 보존 검사를 거쳐 호환 패키지를 적용합니다. 일반적인 실행 패키지 갱신에는 직접 `git pull`할 필요가 없습니다. 실행기 저장소를 ZIP으로 내려받은 경우도 같은 경로로 확인합니다.
- 서비스가 실행 중이면 적용을 미루고 정상 종료 후 다음 시작에서 다시 확인합니다. 다운로드 실패 시 이미 설치된 버전과 기록은 유지합니다.
- **실행기 자체·Python 의존성·채점 이미지 변경**은 현재 자동 교체 범위에 포함되지 않으며 별도 업그레이드 안내가 필요합니다.

**v0.1.0·v0.1.1에서 호환 실행기로 옮기는 경우:** 종료 후 `git pull`로 실행기 파일을 갱신하거나, 이 저장소의 ZIP을 새로 받아 루트 파일을 기존 설치 폴더에 덮어씁니다. `.coderoute` 폴더는 삭제하거나 옮기지 마세요. 이번에는 `launcher.py`·`start.cmd`·`stop.cmd` 자체가 바뀌므로 이 작업이 한 번 필요합니다. 이후 호환 실행 패키지는 선택한 Python에 맞춰 기존 자동 업데이트 경로로 받습니다. 기존 설치의 Python 계열을 강제로 바꾸거나 가상환경을 삭제하지 마세요.

중요한 풀이는 업데이트와 별개로 개인 기록 파일을 내보내 보관해 주세요.

## 실행이 잘되지 않을 때

| 증상 | 먼저 확인할 내용 |
|---|---|
| Python 안내가 나오고 종료됨 | CPython 3.11·3.12·3.13 중 하나의 64비트 버전이 있는지 확인합니다. `py` 또는 PATH의 `python`으로 실행할 수 있어야 합니다. PyPy 전용 환경은 지원하지 않습니다. |
| Docker·채점 준비에 실패함 | Docker Desktop이 실행 중인지, Linux 엔진과 필요한 WSL·가상화 설정이 준비됐는지 확인합니다. |
| 최초 준비가 오래 걸림 | 설치 창의 진행·오류 문구를 확인합니다. 처음에는 의존성과 네 언어 채점 이미지를 준비합니다. |
| 브라우저가 열리지 않음 | 실행 완료 여부를 확인한 뒤 `http://127.0.0.1:8000/`에 직접 접속합니다. 준비 실패 메시지가 있다면 먼저 그 원인을 해결합니다. |
| 포트 충돌 안내가 나옴 | 같은 PC의 다른 코드루트나 8000번 포트를 사용하는 프로그램이 있는지 확인합니다. |
| 업데이트·설치 오류가 남음 | `.coderoute` 폴더를 보관하고 오류 문구를 확인합니다. 설치 명령 오류 로그는 생성된 경우 `.coderoute/home/artifacts/package-command-error.log`에서 볼 수 있습니다. |

현재 상태는 실행기 폴더에서 아래 명령으로 확인할 수 있습니다.

```powershell
.\.coderoute\home\.venv\Scripts\python.exe .\launcher.py status
```

해결되지 않으면 [Issues](https://github.com/dang0321/coderoute-launcher/issues)에 사용 버전, Windows·Python·Docker 환경, 재현 순서와 오류 문구를 적어 주세요. **DB·개인 기록 파일·인증 JSON·토큰·비밀번호·SMTP 설정은 올리지 말고**, 로그와 화면의 개인정보도 가려 주세요.

## 현재 제공 범위

- **Windows 로컬 베타**입니다. macOS·Linux용 실행 패키지는 제공하지 않습니다.
- 같은 Windows PC의 별도 설치 폴더에서 실제 공개 다운로드·최초 설치·웹 응답·재시작 후 기록 보존을 확인했습니다. 같은 배포 파일의 네 언어 Docker 채점과 호환 업데이트·복구는 별도 로컬 시험에서 확인했습니다.
- v0.1.1 운영용 Google 앱의 프로덕션 게시, 운영 계정의 실제 인증·Drive 저장·재다운로드, 별도 빈 DB 복원과 브라우저 자동 동기화를 예제 기록으로 확인했습니다. 수정한 초안과 이전 이력의 보존도 검사했습니다.
- 다른 물리 PC의 설치·Google 연결, 다른 이용자 계정과 대규모 이용 검증은 남아 있습니다.
