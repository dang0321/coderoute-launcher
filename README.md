# CodeRoute · Windows 실행기

원본 개발 저장소 접근 없이 CodeRoute 실행용 패키지를 받는 Windows 실행기입니다. 학습은 로컬 브라우저에서 하고 채점은 이용자 PC의 Docker에서 수행합니다. 이용 가능한 배포 파일은 저장소의 Releases에서 확인합니다. 소스와 패키지의 라이선스·재배포 조건은 아직 미정입니다.

- Python 3.13 64비트(Windows Python Launcher의 `py -3.13`)와 Docker Desktop의 Linux 엔진이 필요합니다.
- `start.cmd`로 시작하고 `stop.cmd`로 종료합니다. 처음 설치에는 패키지·Python 의존성·Docker 이미지 다운로드가 필요합니다.
- `.coderoute/home/`에 계정·기록·Google 설정·가상환경을 보관합니다. 업데이트 때문에 이 폴더를 지우지 않습니다.
- 프로그램은 `.coderoute/releases/`의 버전별 폴더에 두고 현재 버전 정보만 전환합니다. 첫 설치 뒤 시작 시 최대 24시간에 한 번 정식 배포를 확인합니다.
- `launcher.json`은 실행 전용 저장소 `dang0321/coderoute-launcher`의 정식 Release를 확인합니다. 해당 저장소·Release가 준비되지 않았거나 파일 검증에 실패하면 첫 설치를 중단합니다. 개발 저장소 주소·접근 토큰을 넣지 않습니다.
- 실행 중인 서비스·처리 중 작업·변경된 프로그램 파일이 있으면 갱신을 미룹니다. DB·개인 기록 검증 실패 시 이전 DB·프로그램으로 복구하고 같은 패키지 재시도를 보류합니다.
- 실행 중 미룬 업데이트는 정상 종료 후 다음 시작에서 다시 확인합니다. 첫 다운로드·새 버전 확인에는 인터넷이 필요하며, 다운로드 오류가 나도 이미 설치된 버전과 기록은 유지합니다.
- 초기 호환 업데이트는 Python 의존성·업데이트 핵심·채점 컨텍스트가 같은 버전을 대상으로 합니다. 이 항목이 바뀐 배포는 별도 업그레이드 안내가 필요합니다. 실행기 자체의 자동 교체는 아직 지원하지 않습니다.

백엔드 원본 `.py` 대신 `.pyc` 실행물을 받습니다. 바이트코드는 복원·분석될 수 있고 웹 UI·학습 자료와 Docker 채점용 도우미 코드는 이용자 PC에 전달됩니다. 원본 Git 저장소 비공개와 모든 배포 코드의 완전한 은닉은 다릅니다. DB·토큰·SMTP 프로필은 배포하지 않습니다.

Google 연결의 운영용 설정 배포는 아직 별도 준비 중입니다. 기존 PC의 토큰이나 DB를 배포물에 포함하지 않습니다. 기존 개발 환경 기록을 이 설치에 자동으로 복사하지 않으며 개인 기록 내보내기·가져오기 또는 검증된 Drive 연결로 옮깁니다.
